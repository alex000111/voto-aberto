# Iniciar no Windows

Abra `iniciar.cmd` nesta pasta e acesse http://127.0.0.1:3000. Mantenha a janela aberta. Para encerrar, pressione Ctrl+C.

Se o site já estiver aberto, não inicie outro servidor na mesma porta. A configuração do banco está em CONFIGURAR-SUPABASE.md. Sem banco, as telas exibem a indisponibilidade explicitamente.

Em outro computador com Node.js 24, execute `npm.cmd ci` antes de iniciar.
